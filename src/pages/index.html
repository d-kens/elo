How it works

Three steps, repeated.

  1. 01

    Pick a path

    Each path is a set of modules in a fixed order, from the basics to working like a professional.

  2. 02

    Read the notes

    Every module has detailed notes that build on the one before. Take them at your own pace.

  3. 03

    Do the work

    Most modules end with a lab or a project, so you finish each step with something you built yourself.
